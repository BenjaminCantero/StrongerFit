# Motor de nutrición

TypeScript puro para RF-09 (SRS 8.5): TMB con Mifflin-St Jeor, gasto total por
factor de actividad, meta con déficit o superávit limitados (BR-17), piso de
seguridad (BR-16), sin déficit con riesgo declarado (BR-19) y macros 4/4/9.
Energía al entero; macros al gramo. Cada resultado incluye `ruleVersion`.

Sin sexo declarado se usa el promedio de las constantes (−78) y el piso mayor;
es una decisión provisional hasta resolver SRS 11.1. Los valores son referencia
inicial y requieren revisión profesional antes del lanzamiento público.
