# Recursos de vista previa

`preview-avatar.jpg` es el avatar de la referencia HTML de Stitch aportada por el
usuario. Se almacena localmente para que la vista previa no dependa de ese enlace
externo. Solo se muestra en desarrollo y no representa una cuenta autenticada.

`preview-exercise.jpg` proviene del HTML de sesión de entrenamiento aportado por el
usuario y se usa como ilustración del prototipo. No constituye un catálogo de
ejercicios revisado o una certificación de técnica.

`preview-chicken.jpg`, `preview-avocado.jpg` y `preview-bread.jpg` son las imágenes
del HTML de registro de alimento aportado por el usuario. Ilustran el catálogo de
ejemplo y no implican verificación de nutrientes, procedencia o alérgenos.

Las tipografías se distribuyen mediante los paquetes `@expo-google-fonts/literata`
y `@expo-google-fonts/nunito-sans`, que incluyen sus correspondientes licencias.


Las imágenes `preview-progress-weights.jpg` y `preview-progress-recovery.jpg`
provienen del HTML de Progreso entregado por el usuario el 30 de octubre de 2026.
Se empaquetan localmente como recursos de diseño; no representan registros ni
fotografías personales del usuario. La nota corporal y la reflexión mantienen
texto legible y las imágenes no contienen controles.
