# Recursos de vista previa

`preview-avatar.jpg` es el avatar de la referencia HTML de Stitch aportada por el
usuario. Se almacena localmente para que la vista previa no dependa de ese enlace
externo. Solo se muestra en desarrollo y no representa una cuenta autenticada.

Las tipografías se distribuyen mediante los paquetes `@expo-google-fonts/literata`
y `@expo-google-fonts/nunito-sans`, que incluyen sus correspondientes licencias.
